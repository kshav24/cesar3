\subsection{What Changed}

+  size_t num_emitting;

\subsection{Why}
To eliminate the silent-state dependency bottleneck inside Viterbi.c, we are implementing a topological sort (Kahn's algorithm) to explicitly partition the HMM into purely parallel emitting states and strictly sequential silent states. The \texttt{num_emitting} field stores the array index pivot between these two domains.
